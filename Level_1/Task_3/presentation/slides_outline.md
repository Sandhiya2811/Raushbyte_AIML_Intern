# Slide 2 – What is Artificial Intelligence?

## On-Slide Content

* **Definition:** Computer systems that perform tasks normally requiring human intelligence
* **Understand language** — voice assistants, translation
* **Recognize images** — face unlock, photo tagging
* **Find patterns & make predictions** — spam filtering, demand forecasting
* **Generate content** — text, images, code (e.g., ChatGPT)
* **Why AI matters today:** huge data + affordable computing + better algorithms


---

# Slide 3 – Major AI Concepts

## On-Slide Content

* **AI** — the broad field of building intelligent machines
* **Machine Learning** — learning patterns from data (e.g., spam filters)
* **Deep Learning** — many-layered neural networks (e.g., face recognition)
* **NLP** — understanding & generating language (e.g., Google Translate)
* **Computer Vision** — understanding images & video (e.g., X-ray screening)
* **Generative AI** — creating new content (e.g., ChatGPT)

> **Note:** NLP, Computer Vision and Generative AI are application areas that usually build on ML/DL — not strict subsets.




---

# Slide 4 – How AI Works

## On-Slide Content

* **Data Collection** — gather relevant, representative examples
* **Preprocessing** — clean and prepare the data
* **Training** — the model learns by adjusting internal parameters
* **Evaluation** — tested on unseen data to measure real accuracy
* **Inference** — the deployed model makes predictions on new inputs
* **Monitoring** — track performance; retrain when needed

> **Note:** Workflows vary — rule-based systems (e.g., a pattern-matching chatbot) need no training step.

# Slide 6 – Generative AI and LLMs

## On-Slide Content

* **Generative AI** creates new content: text, images, audio, code
* **LLMs** — large neural networks trained on massive text datasets
* They generate responses by predicting the next word, piece by piece
* **Uses:** chatbots, coding assistants, summarization, document Q&A
* **Limitations:** hallucinations, bias, limited context, privacy concerns

# Slide 8 – AI Tools and Development Workflow

## On-Slide Content

### Development Pipeline

**Problem Definition → Data Collection → Data Cleaning → Exploratory Data Analysis → Model Selection → Training → Evaluation → Deployment → Monitoring**

### Key Points

* Most project effort goes into the **data stages**: collection, cleaning, EDA
* **Deployment & monitoring** are real stages — a model in a notebook delivers no value
* Typical tools: Python · Pandas · Scikit-learn · TensorFlow/PyTorch · Hugging Face · Streamlit/FastAPI · Git
* Tool choice always **depends on the project** — there is no single "correct" stack

## On-Slide Content

| **✅ Benefits**                 | **⚠️ Challenges**                  |

# Slide 10 – Ethical and Responsible AI

## On-Slide Content

* **Fairness** — avoid biased outcomes across groups
* **Transparency** — people should know when AI is used and why decisions are made
* **Privacy & Security** — protect personal data
* **Accountability** — clear responsibility for AI-driven decisions
* **Human Oversight** — humans stay in the loop for high-impact decisions

> **AI should support human decision-making — not blindly replace human judgment in high-impact situations.**
